Grand Wedding Photography — V3 Multi-page Website

Pages
- index.html — Home
- photography.html — Wedding stories + complete 140-photo archive
- story.html?id=... — Story detail galleries
- films.html — Supplied wedding films
- packages.html — Senior, Elegant and Signature packages (no tabs / no package image modal)
- book.html — Package-aware, multi-event WhatsApp booking form
- about.html — Brand / creative approach
- contact.html — Contact information + WhatsApp quick message

Important
- The existing assets/ folder structure and asset paths were preserved.
- All 140 supplied gallery images are included in the Photography archive and grouped into story sequences.
- Both supplied videos remain in assets/videos/ and are loaded only when the visitor presses play.
- Desktop hero remains assets/hero/hero-desktop.webp.
- Mobile hero remains assets/hero/hero-mobile.webp.
- Package selection links directly to book.html and pre-selects the chosen package.
- The booking form supports 1–4 separate events, each with its own event type, date, shift and venue.
- The current booking flow opens WhatsApp; it does not claim to store bookings in a database.
- The story titles are editorial labels based on the supplied visual sequences. They can be renamed later if client/event names are provided.
